# 一键部署与打包

## 最小启动

```bash
cp .env.example .env
# 至少设置：非占位 API_TOKEN；LLM_MOCK=true 或 LLM_API_KEY
./scripts/bootstrap.sh
```

健康检查：`http://127.0.0.1:${APP_PORT:-8080}/health`

## Compose 拓扑

```text
默认（一体）
  factor-api  ── 内嵌 job worker（WORKER_ENABLED=true）
              ── 采集/摘要默认关闭

拆分（BOOTSTRAP_PROFILE=split）
  factor-api       WORKER_ENABLED=false
  factor-worker    python -m factor_backend worker
  factor-collector python -m factor_backend collector
```

> Redis / market-mcp 占位服务已移除。MCP 行情仍为代码 stub（`MCP_ENABLED`），未提供独立容器。

## 配置真相源

| 来源 | 用途 |
|------|------|
| `.env` / 环境变量 | Settings：鉴权、worker、采集、门槛种子 |
| SQLite `llm_config` / `prompt_overrides` | 前端可改的 LLM 与提示词 |
| `config/default.yaml` | **仅参考，运行时不加载** |

## 本地开发（非 Docker）

```bash
pip install -e ".[dev]"
uvicorn factor_backend.main:app --host 127.0.0.1 --port 18081

cd frontend && npm install && npm run dev -- --host 127.0.0.1 --port 5174
```
