# 资讯分析与采集

> 模块说明：多源资讯/研报入库 → LLM 资讯摘要（非因子）→ 可选人工发起因子流水线。

相关代码：`backend/factor_backend/services/report_ingest/`、`news_summarize.py`、`frontend/src/views/ReportsView.vue`。

---

## 行为概览

| 能力 | 说明 |
|------|------|
| 定时采集 | 后端启动后后台线程轮询；默认每 **600s**（`REPORT_COLLECTOR_INTERVAL_SEC`） |
| 手动同步 | 前端「立即同步」或 `POST /api/v1/reports/collect/run` |
| 入库后摘要 | 自动入队 LLM 摘要（`NEWS_SUMMARIZE_ENABLED`，提示词 `news_summarize`） |
| 因子流水线 | **不自动开跑**；需人工点「因子」→ `POST /api/v1/jobs` |
| 查看原文 | `GET /api/v1/reports/{id}/content`；侧栏展示摘要+正文 |

开关：`REPORT_COLLECTOR_ENABLED=true|false`。

## 资讯源

配置：`REPORT_COLLECTOR_SOURCES`（逗号分隔）。

| key | 名称 | 登录 | 内容 |
|-----|------|------|------|
| `eastmoney_report` | 东财研报 | 否 | 个股/行业/策略/宏观等；PDF 优先 **http** 下载 |
| `eastmoney_news` | 东财资讯 | 否 | 栏目新闻（导读/股市/公司/宏观/产经/国际） |
| `wallstreetcn` | 华尔街见闻 | 否 | 7x24 + 文章 |
| `sina` | 新浪财经 | 否 | 滚动资讯 |
| `ths` | 同花顺 | 否 | 快讯 |
| `jin10` | 金十数据 | 否 | 快讯（标题取自 `data.title` 或正文首句） |
| `luobo` | 萝卜投研 | **是** | 资讯流 + 研报列表；需 `LUOBO_CLOUD_SSO_TOKEN` |

默认源字符串：

```text
eastmoney_report,eastmoney_news,wallstreetcn,sina,ths,jin10,luobo
```

### 东财研报要点

- 个股/行业：`/report/list`；策略/宏观/晨报：`/report/jg`（再解析真实 `AP…` infoCode）
- PDF：`http://pdf.dfcfw.com/pdf/H3_{infoCode}_1.pdf`（`https` 易返回 JS 挑战页）
- 重抓：`POST /api/v1/reports/{id}/refetch-pdf`

### 萝卜投研取 token

1. 登录 https://robo.datayes.com  
2. Cookie 复制 `cloud-sso-token` → `.env` 的 `LUOBO_CLOUD_SSO_TOKEN`  
3. 重启后端；状态接口字段 `luobo_configured`

## 前端「资讯分析」

- 菜单路径：`/reports`
- 列表：摘要状态 / 不建议因子分析提示 / 来源筛选
- 原文抽屉：摘要、重抓 PDF、重新摘要
- 提示词：提示词管理 → **资讯分析**（`news_summarize`）

宏观/晨报/正文不完整：可入库与摘要，因子按钮会提示「不建议分析」。

## 主要 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/reports` | 列表 |
| GET | `/api/v1/reports/{id}/content` | 原文 + `news_summary*` |
| POST | `/api/v1/reports/{id}/summarize` | 重跑摘要 |
| POST | `/api/v1/reports/summarize/backfill` | 未摘要批量入队 |
| POST | `/api/v1/reports/{id}/refetch-pdf` | 东财 PDF 重抓 |
| POST | `/api/v1/reports/collect/run` | 手动采集一轮 |
| GET | `/api/v1/reports/collect/status` | 采集状态 |

## 环境变量速查

| 变量 | 默认 | 说明 |
|------|------|------|
| `REPORT_COLLECTOR_ENABLED` | `true` | 定时采集开关 |
| `REPORT_COLLECTOR_INTERVAL_SEC` | `600` | 间隔秒（最小 60） |
| `REPORT_COLLECTOR_SOURCES` | 见上 | 源列表 |
| `REPORT_COLLECTOR_QTYPES` | `0,1,2,3` | 东财研报类型 |
| `REPORT_COLLECTOR_NEWS_COLUMNS` | `350,344,…` | 东财资讯栏目 |
| `LUOBO_CLOUD_SSO_TOKEN` | 空 | 萝卜登录 |
| `NEWS_SUMMARIZE_ENABLED` | `true` | 入库后摘要 |
| `NEWS_SUMMARIZE_WORKERS` | `2` | 摘要并发线程 |

详见仓库根目录 `.env.example`。
